# ✈️ Airline Aviate X  
### Airline Management System (C# Windows Forms)

Airline Aviate X is a desktop-based Airline Management System developed as part of the **Visual Programming** course at the **University of Kelaniya**.  
The system is designed to efficiently manage airline operations by providing separate interfaces for passengers and administrators.

---

## 📌 Project Overview

Airline Aviate X supports core airline management functionalities such as flight searching, flight scheduling, booking management, and revenue reporting.  
It focuses on clear role separation between **users (passengers)** and **administrators**, ensuring structured access and better system control.

This project was developed for academic purposes and serves as a foundational airline management solution that can be expanded into a full-scale reservation system.

---

## 👥 User Roles

### 🔹 User (Passenger)
- Search available flights by:
  - Departure
  - Destination
  - Date
- View basic flight details:
  - Flight ID
  - Departure & Destination
  - Date & Time

> ⚠️ Note:  
> The user module is **read-only**. Booking and login features are not included in the current version.

---

### 🔹 Admin
Admins have full control over airline operations through a secure login system.

Admin capabilities include:
- Flight management (Add, Update, Delete, View)
- Booking management
- Revenue report generation
- Profile and credential management

---

## 🧩 Key Features

### ✈️ Flight Management
- Add new flights with validation
- Update existing flight details
- Delete cancelled or inactive flights
- View all available flights in a tabular format

### 📖 Booking Management
- View all flight bookings
- Cancel bookings with confirmation
- Automatically update the database after deletion

### 📊 Reports
- Generate revenue reports by destination
- Analyze high and low revenue routes
- Support data-driven decision making

### 👤 Admin Profile Management
- View admin profile details
- Update login credentials securely
- Password validation and confirmation handling

### 🖥️ Graphical User Interface
- User-friendly Windows Forms GUI
- Clear navigation between modules
- Error handling through dialog messages
